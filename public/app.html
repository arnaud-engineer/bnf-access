Cette page permet à votre navigateur de reconnaître BnF Access comme une application installable.

Ouvrir BnF Access Retour à la FAQ

Comment l'ajouter à l'écran d'accueil ?

Sur Firefox mobile, ouvrez le menu du navigateur depuis cette page, puis choisissez l'option permettant d'ajouter BnF Access à l'écran d'accueil.

Une fois ajoutée, l'application s'ouvrira en plein écran et vous retrouverez la page principale de BnF Access.

Vous préférez le site classique ?

Retournez dans la FAQ, désactivez le mode application web, puis la page se rechargera en mode site web normal.
